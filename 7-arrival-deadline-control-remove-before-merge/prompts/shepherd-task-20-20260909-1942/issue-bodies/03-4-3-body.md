## Implement

Create:

- `src/main/java/org/eclipse/cargotracker/interfaces/booking/web/ChangeArrivalDeadlineDate.java`

Use this shape:

```java
@Named
@ViewScoped
public class ChangeArrivalDeadlineDate implements Serializable {
    private static final long serialVersionUID = 1L;

    private String trackingId;
    private CargoRoute cargo;
    private Date arrivalDeadlineDate;

    @Inject
    private BookingServiceFacade bookingServiceFacade;
}
```

Provide:

- `getTrackingId()` and `setTrackingId(String)`
- `getCargo()`
- `getArrivalDeadlineDate()` and `setArrivalDeadlineDate(Date)`
- `load()`
- `changeArrivalDeadline()`

`load()` must call `bookingServiceFacade.loadCargoForRouting(trackingId)`, retain the `CargoRoute`, parse its date-only arrival deadline with a new `SimpleDateFormat("MM/dd/yyyy")`, and store the resulting `Date`. Follow repository-standard JSF error handling for parse failure; do not return null, print a stack trace, or silently continue.

`changeArrivalDeadline()` must reject a null selection, call `bookingServiceFacade.changeDeadline(trackingId, arrivalDeadlineDate)`, and only after success call `PrimeFaces.current().dialog().closeDynamic("DONE")`. A failed facade call must remain visibly failed and leave the dialog open.

Add a container-free JUnit test when practical, using a hand-written fake facade, to cover correct tracking-ID loading, date parsing, exact submit delegation, malformed DTO date failure, and null selected-date rejection.

## Completion gates

- The bean is serializable and uses the established CDI `@Named` plus JSF `@ViewScoped` annotations.
- The bean imports facade DTOs, not cargo domain model or repository classes.
- `./mvnw clean package -Popenliberty` succeeds on JDK 17.
- Tests discriminate malformed input from a valid date and prove failed/null submission cannot produce a success-shaped dialog close.
- Prior application and facade gates remain intact.
- Review the diff to confirm no launcher class, XHTML, dashboard table, runtime, persistence, or dependency change.

- Shared mutable `SimpleDateFormat`, a DTO redesign, or formatted-string service parameters.
- New chronological business rules, mocking dependencies, namespace/runtime migration, or unrelated UI refactoring.
