The resolved boundary is `void changeDeadline(String trackingId, Date arrivalDeadline)` on `BookingServiceFacade`. `DefaultBookingServiceFacade` converts only the identifier with `new TrackingId(trackingId)` and passes the same `Date` to the application service. No domain object, formatted date string, command DTO, JSF type, or PrimeFaces type crosses this facade API.

Research established that this historical baseline's mandatory automated gate is the JDK 17 Open Liberty package build; the existing Arquillian runtime remains tied to remote Payara. A focused container-free test may use a hand-written fake, but must not add Mockito or another dependency.

## Completion gates

- Existing facade consumers compile without changes.
- `./mvnw clean package -Popenliberty` succeeds on JDK 17.
- Task 1's application-layer test remains unchanged and compiles.
- A focused test, if added, fails if the facade parses/formats the date, delegates more than once, changes the date value, or performs repository work.
- Review the diff to confirm no JSF, PrimeFaces, XHTML, domain mutation, repository, runtime, or dependency changes.

## Out of scope

- Loading or mutating `Cargo` in the facade.
- Calling `CargoRepository.store(...)` from the facade.
- Parsing formatted dates or adding a command DTO.
- JSF/PrimeFaces types or behavior.
- New mocking/test dependencies, Payara modernization, namespace migration, or unrelated facade refactoring.
