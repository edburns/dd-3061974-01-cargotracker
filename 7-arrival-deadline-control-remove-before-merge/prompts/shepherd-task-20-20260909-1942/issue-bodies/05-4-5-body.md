- keeps displaying `cargoNotRouted.arrivalDeadlineDate`;
- uses the existing Font Awesome edit-icon style;
- has a stable ID such as `arrivalDeadlineToUpdate`;
- registers a `dialogReturn` Ajax listener;
- invokes `changeArrivalDeadlineDateDialog.handleReturn`;
- updates `tableNotRouted`;
- provides the exact tooltip `Click to change cargo arrival deadline date.`

Follow the adjacent Destination column's structure and styling. Do not alter destination editing, tracking-ID routing, or any other cargo table.
